# Code of Conduct

<p align="right">
  <strong>繁體中文</strong> · <a href="#english">English</a>
</p>

## 我們的承諾

OneDirect 希望建立一個尊重、專業及可協作的開源社群。無論年齡、身體狀況、族裔、性別認同、經驗程度、國籍、宗教或技術選擇，參與者都應受到尊重。

## 期望行為

- 對技術問題保持直接、清楚及善意。
- 針對程式、架構與證據討論，不攻擊個人。
- 尊重 module boundaries 及維護者決定。
- 接受 constructive feedback。
- 發現安全或私隱問題時，依 `SECURITY.md` 私下回報。
- 協助新貢獻者理解 setup、tests 及 contracts。

## 不可接受行為

- 騷擾、歧視、威脅或人身攻擊。
- 公開他人私人資訊。
- 張貼 credentials、production payload 或未去敏化資料。
- 故意繞過 security review、CI 或 dependency rules。
- 持續干擾 discussion、issue 或 pull request。
- 報復提出問題或安全疑慮的人。

## Enforcement

維護者可移除、編輯或拒絕不符合本政策的内容，並可視情況限制參與。重大事件應透過 Organization 的私人 maintainer channel 回報，不要在 public issue 公開敏感細節。

## Scope

本政策適用於 repository、issues、pull requests、discussions、review comments、project events 及以本專案名義進行的公開互動。

## Attribution

本政策參考 open-source community standards，為 OneDirect 的雙語專案情境調整。

# Code of Conduct

## Our Pledge

OneDirect aims to be a respectful, professional, and collaborative open-source community. Participation should be free from harassment regardless of age, disability, ethnicity, gender identity, experience, nationality, religion, or technology choice.

## Expected Behavior

- Be direct, clear, and kind when discussing technical problems.
- Critique code, architecture, and evidence rather than people.
- Respect module boundaries and maintainer decisions.
- Accept constructive feedback.
- Report security and privacy issues privately through `SECURITY.md`.
- Help new contributors understand setup, tests, and contracts.

## Unacceptable Behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing another person's private information.
- Posting credentials, production payloads, or unsanitized data.
- Deliberately bypassing security review, CI, or dependency rules.
- Sustained disruption of discussions or pull requests.
- Retaliation against anyone raising a concern.

## Enforcement

Maintainers may remove, edit, or reject content and may limit participation when necessary. Significant incidents should be reported through the organization's private maintainer channel, not in a public issue.

## Scope

This policy applies to repositories, issues, pull requests, discussions, reviews, project events, and public interactions made on behalf of the project.

## Attribution

This policy adapts common open-source community standards for OneDirect's bilingual project context.
