## 社群用途

- 討論 setup、provider integration 及 module usage。
- 分享 fictional fixtures 或 reproducible examples。
- 協調 roadmap、feature discussion 及 release testing。
- 公告示範、文件或 release 更新。

## 不要分享

- API keys、access tokens、cookies 或 passwords。
- Production request／response payload。
- 真實政府或 operator endpoint。
- 私人用戶位置、車輛資料或帳戶資料。
- 未經授權的 source dump。

## Bug Report Checklist

1. 使用的 package 及版本。
2. Minimal reproduction。
3. Expected／actual behavior。
4. 已去敏化的 log。
5. 是否與 `DataProvider` implementation 有關。

> These channels are for public collaboration only. Never post credentials, production payloads, private locations, or unsanitized data.

| Channel | Where / how |
| --- | --- |
| 💬 **WhatsApp Channel** | [Join the OneDirect channel](https://whatsapp.com/channel/0029VbE05XjDp2QCXyMP3Y04) |

| 🔒 **Security reports** | Follow [SECURITY.md](./SECURITY.md) |
| 📄 **License** | [Apache-2.0](./LICENSE) |

## What the Community Is For

- Setup, provider integration, and module usage.
- Fictional fixtures and reproducible examples.
- Roadmap, feature discussion, and release testing.
- Demo, documentation, and release announcements.

## Never Share

- API keys, access tokens, cookies, or passwords.
- Production requests or responses.
- Real government or operator endpoints.
- Private user locations, vehicle data, or account data.
- Unauthorized source dumps.

## Bug Report Checklist

Include the package and version, a minimal reproduction, expected and actual behavior, sanitized logs, and whether a custom `DataProvider` is involved.
